How it works Rust, A*, and ROS 2

One navigation core, two ways to run it. Here, Rust runs as WebAssembly in your browser. A* finds a route on a grid; a simple controller turns the robot and follows each segment. A new valid goal immediately replaces the old route.

The same Rust code runs natively behind a Python ROS 2 node. That node exposes a navigation action and publishes the map, path, odometry, velocity, and transforms. This standalone browser demo does not run ROS 2 middleware or connect to a robot.

Click a goal→Rust A*→Controller→Robot pose

Keyboard: focus the map, use arrow keys to choose a cell, then press Enter. Pause holds the robot in place. Reset returns it to the start.
