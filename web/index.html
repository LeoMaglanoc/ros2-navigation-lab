How it works Rust, A*, and ROS 2

Real ROS 2 nodes run in this tab. ROS2WASM compiles ROS 2's rcl node API and its browser middleware to WebAssembly. The browser_ui node publishes your destination; the navigator node receives it and calls the Rust A* planner and controller. State returns through a ROS subscription before it reaches the canvas.

browser_ui→ /goal_pose →navigator + Rust→ /state →Canvas
